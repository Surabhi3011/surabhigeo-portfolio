EPSG & Coordinate System Finder

Tech
Python
Type
Personal project

Problem

Looking up the correct EPSG code or coordinate reference system for a dataset usually means switching between multiple reference sites, which slows down otherwise quick GIS setup tasks.

Approach

Built a lightweight Python tool for coordinate reference system lookup, consolidating the lookup step into a single script-based utility.

  • Accepts common identifiers (EPSG code, name, or region) as lookup input.
  • Returns matching coordinate reference system details.
  • Runs locally without needing a browser-based lookup tool.

Outcome

A small, reusable utility that speeds up a task most GIS workflows hit early on — confirming the right CRS before any spatial processing begins.
