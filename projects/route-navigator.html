Route Navigator

Tech
Node.js, open source routing & elevation data
Type
Personal project

Problem

Free, general-purpose route planners rarely surface alternate paths or terrain data together — useful when comparing routes for hiking, cycling, or field logistics where elevation gain matters as much as distance.

Approach

Built a Node.js application that consumes open source routing and elevation data to compute the best route between a source and destination, along with alternate route options.

  • Fetches routing data from open source APIs and parses route geometry.
  • Computes primary and alternate routes for the same source/destination pair.
  • Derives elevation profiles along each route for terrain comparison.

Outcome

A working Node.js tool that returns route options with elevation context in a single request, useful as a lightweight alternative to piecing together multiple mapping tools.
